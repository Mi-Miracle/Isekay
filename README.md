# ⚔️ Хроніки Дивосвіту

Аніме-ісекай RPG у світі меча й магії. Тебе збиває Вантажівка-кун, богиня видає чіт — і ти прокидаєшся в **Дивосвіті**.

## Завантажити

Сторінка релізів: **https://github.com/Mi-Miracle/Isekay/releases/latest**

- `Dyvosvit-Setup-x.y.z.exe` — інсталятор, **оновлюється сам** у фоні.
- `Dyvosvit-Portable-x.y.z.exe` — без встановлення; гра сама знаходить нову версію, завантажує її поруч і перезапускається.

Перевірити оновлення можна і вручну: кнопка «Оновлення» на стартовому екрані.

## Що є в грі

- **Автооновлення**: при запуску гра сама перевіряє GitHub, завантажує нову версію і перезапускається.
- **Світ v3**: велика мапа (440×300), 6 континентів (Серединні Землі, Сильванор, Сходосвіт, Крижані Землі, Пекучий Південь, Демонія) та острови. Відстані між поселеннями більші.
- **Народи**: людська Імперія з 10 васальними королівствами та вільні людські королівства. Ельфи, темні ельфи, гноми, орки, гобліни, звіролюди, напіврослики й драконіди мають власні королівства.
- **Живий світ**: армії королівств і Володаря Демонів фізично марширують дорогами, б'ються й беруть в облогу. Є вартові патрулі, а час можна запустити кнопкою (⏸ ▶ ⏩ ⏭ або пробіл).
- **ШІ королівств**: обирає курс (будівництво, торгівля, армія, війна), укладає торгові угоди, розбудовує міста, зводить фортеці й казарми. Кожна раса має свій стиль війська.
- **НПС-герої**: мандрують світом, зачищають підземелля, б'ються з ордами й гинуть. Можна поговорити, позмагатися або взяти героя в загін.
- **Класи**: 10 класів (нові — Берсерк, Списник, Бард). Шлях розвитку: клас ІІ на 10 рівні, клас ІІІ на 20, вознесіння на 30. Навичок стало вдвічі більше.
- **Спорядження**: 19 видів зброї, кольчуга, 8 рівнів металу (до Божественного), рідкість до Міфічної, 15 унікальних легендарок.
- **Ресурси й крафт**: родовища на мапі (рудники, кратери метеоритів, прадавні ліси, рибні озера, шовкові печери…). Кування й кравецтво будь-якої зброї та броні. З монстрів випадає лут.
- **30 благословень**.
- **Звук**: офлайн українська нейроозвучка (Piper, голоси Микита / Тетяна / Лада, одноразове завантаження ~80 МБ) і 8 музичних тем.
- **Анімації**: заставка при запуску, приколи на стартовому екрані.
- **Чіт-меню для тестування**: клавіша ` або F10.

## Запуск із коду

```bash
npm ci
npm start        # гра
npm test         # тести логіки
npm run dist:win # збірка .exe
```

Кожен push у `main` проходить тести й збирає Windows-версію. Якщо `version` у `package.json` нова, CI сам публікує реліз, і гравці отримують оновлення.
