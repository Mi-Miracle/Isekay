# ⚔️ Хроніки Дивосвіту

Аніме-ісекай RPG у світі меча й магії. Тебе збиває Вантажівка-кун, богиня видає чіт — і ти прокидаєшся в **Дивосвіті**.

## Завантажити

Сторінка релізів: **https://github.com/Mi-Miracle/Isekay/releases/latest**

- `Dyvosvit-Setup-x.y.z.exe` — інсталятор, **оновлюється сам** у фоні.
- `Dyvosvit-Portable-x.y.z.exe` — без встановлення; гра сама знаходить нову версію, завантажує її поруч і перезапускається.

Перевірити оновлення можна і вручну: кнопка «Оновлення» на стартовому екрані.

## Що є в грі

- **Світ**: 4 континенти (серед них Демонія), острови, морські шляхи. Імперія з десятьма васальними королівствами, незалежні держави, герцогства, графства, баронства. Столиці, міста, фортеці, порти, села й шахти мають власні регіони на мапі.
- **Небезпечні місця**: Ліс Смерті, Поля Скелетів та інші, плюс понад 50 підземель із босами.
- **ШІ держав**: війни, союзи, повстання за незалежність. Імперія воює єдиним блоком. Володар демонів Малдраґор висаджує армії з моря, з диких земель лізуть орди, трапляються катастрофи. Королівства мобілізуються й відбиваються.
- **Персонаж**: 9 рас (і «бог», який чомусь стає гобліном), 16 чітів-благословень, кастомізація вигляду, 12 слотів екіпірування.
- **Розвиток**: бойові класи з рангами навичок, підвищенням класу та вознесінням. Робочі професії: ковальство, алхімія, кулінарія, фермерство, лісорубство тощо. Соціальні титули від простолюдина до лицаря й барона.
- **Володіння**: власний будинок із кімнатами, городом і скринею. Купівля баронства, будівництво, податки, лояльність селян.
- **Бій**: партія з товаришів і пітомця, наміри ворогів, навички монстрів, ліміт-брейк із кат-сценою.
- **Транспорт**: коні та інші скакуни, кораблі.
- **Піксель-арт і озвучка**: персонажі й монстри, звукові «бурмотіння» діалогів або синтез мовлення.
- **Керування**: WASD/стрілки рухають мапу, Q/E масштабують, квести позначені на мапі, є мінімапа.

## Запуск із коду

```bash
npm ci
npm start        # гра
npm test         # тести логіки
npm run dist:win # збірка .exe
```

Кожен push у `main` проходить тести й збирає Windows-версію. Якщо `version` у `package.json` нова, CI сам публікує реліз, і гравці отримують оновлення.
