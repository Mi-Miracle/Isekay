# 🗡️ Ісекай: Хроніки Ельдорії

Аніме-RPG у світі меча і магії. Тебе збиває вантажівка-кун, богиня Люмі (трохи винна) перероджує тебе в Ельдорії — а там шість королівств, імперія, війни, гільдія шукачів пригод і Король Демонів, який дуже голосно хропе.

## ▶️ Як запустити
**Windows:** завантаж `Isekay-Portable-*.exe` з [Releases](../../releases) (або з артефактів GitHub Actions) і запусти. Інсталяція не потрібна. Є також інсталятор `Isekay-Setup-*.exe`.

**З коду:** `npm install` → `npm start`.

## 🌍 Світ
- Процедурний континент: рельєф, ріки, ліси, гори, пустелі, тундра, болота, Попелища Демонів.
- **1 імперія + 6 королівств** (султанат, сьоґунат, ельфійське, підгірне, нордлінги, слов'янське) з різною культурою й назвами.
- Феодальна ієрархія: **Держава → Герцогство → Графство → Баронство** (столиці, міста, містечка, замки, порти, шахтарські селища, села).
- Дороги (тракти й стежки), прокладені з урахуванням рельєфу.
- Режими мапи: рельєф, політична (з окупацією), де-юре, небезпека.

## 👑 ШІ держав
Кожна держава живе сама: правителі з рисами характеру, казна, військо, стабільність, відносини. Оголошують війни (претензії на землі де-юре), кличуть союзників, армії маршують дорогами, б'ються, беруть в облогу, підписують мир і анексують землі. Королі помирають, бувають весілля, чуми, повстання, відродження знищених держав, страх перед гегемоном. Все пишеться в **Хроніку**.

## 🧝 Герой
- Рулетка чит-благословень: Оцінка, Досвід, Безмежна мана, Удача дурня, Друг-слиз, Кулінар-бог.
- 7 бойових класів (Мечник, Лучник, Маг, Жрець, Ассасин, Паладин, Монах з кастетами) по 5 навичок, другий клас з 15 рівня.
- 6 професій: травництво, гірництво, рибальство, ковальство, алхімія, кулінарія — кожна з мінігрою. Плюс злам замків і кості в таверні.
- Гільдія шукачів пригод: ранги F → SSS, іспити, квести (полювання, збір, доставка, зачистка, нагорода за голову, найманство у війнах держав).
- Підземелля з туманом війни, пастками, міміками, скринями та босами. 3 Осколки Печаті → Цитадель Короля Демонів.
- Таверни, крамниці, кузні, храми, арени, королівські двори, купівля баронського титулу.

## ⌨️ Керування
Мапа — перетягування мишкою, коліщатко — масштаб, клік — інфо, подвійний клік — подорож.
`C` персонаж · `I` інвентар · `K` навички · `P` професії · `J` квести · `R` держави · `H` хроніка · `1–4` режими мапи · `Space` до гравця · `Esc` меню · `F11` повний екран.
У бою — `ПРОБІЛ`, коли стрілка в золотій зоні.

## 🧪 Тести
- `npm test` — генерація світу (5 сидів), ієрархія, зв'язність доріг, симуляція політики 5 років, бій, прокачка, квести, збереження/завантаження.
- `npm run selftest` — запускає гру в Electron, проходить сценарій (нова гра, мапа, гільдія, бій, усі мініігри, підземелля, save/load) і робить скріншоти.
