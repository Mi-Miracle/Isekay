# Музика автора, вбудована в гру

Усе, що лежить у цій теці, потрапляє в `.exe` — і грає **в усіх гравців**.

- `track1.mp3`, `track2.mp3`, `track3.ogg`… (будь-яка назва, крім `menu*`) — грають у грі впереміш із 8-бітною музикою
  (поле, ліс, пустеля, зима, місто, таверна, дім, море).
- `menu.mp3` (або `menu1.mp3`, `menu2.mp3`…) — грає в головному меню.
- Формати: `.mp3`, `.ogg`, `.wav`. Бій, боси й підземелля лишаються зі своєю музикою.

Як додати без програм: GitHub → репозиторій → тека `godot/assets/audio/custom` → **Add file → Upload files** → перетягни файли → **Commit changes**.
Після коміту GitHub сам збере нову версію гри (кожен трек збільшує розмір .exe; mp3 ~128 кбіт/с — це ~1 МБ на хвилину).

Важливо: додавай лише музику, яку маєш право поширювати (свою, з дозволом автора або з вільною ліцензією) — бо гра публічна.
